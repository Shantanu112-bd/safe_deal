## Advanced Feature — Fee Sponsorship

Gasless transactions using Stellar fee bump.
Buyers need zero XLM to use SafeDeal.
SafeDeal pays the 0.00001 XLM network fee.

Implementation: /frontend/src/lib/feeBump.ts

Provider: Vercel Logs + localStorage events

  payment_locked, payment_released, errors

## Tech Stack

- Smart Contracts: Rust + Soroban (Stellar)
- Frontend: Next.js 14 + Tailwind CSS
- Blockchain: Stellar Testnet
- Stablecoin: USDC
- Wallet: Freighter + Albedo
- Deployment: Vercel + GitHub Actions
- CI/CD: GitHub Actions (148 tests)

## Local Setup

```bash
git clone https://github.com/Shantanu112-bd/Safe-Deal.git
cd Safe-Deal/frontend
npm install
cp .env.local.example .env.local
npm run dev
```
